# Acme SDK Guide

This is documentation. It *mentions* commands and secrets in prose but does not
run anything itself.

To authenticate, set your `API_KEY` and use `curl` to call the endpoint. Tokens
and secrets are described in the reference section. The SDK reads your
`ACME_TOKEN` from the environment.

Refer users to the official docs for the exact request shapes.
